# AGENTS.md — mebuscosarl.com

Ce fichier guide les agents IA qui explorent le site de Mebusco SARL, cabinet de conseil, études et formation basé à Yaoundé, Cameroun.

## Configuration

Site vitrine statique (React pré-rendu), aucune authentification ni configuration requise pour consulter le contenu. Toutes les pages sont accessibles publiquement.

## Usage

- Pour un résumé structuré du site, lire [llms.txt](https://mebuscosarl.com/llms.txt) ou la version complète [llms-full.txt](https://mebuscosarl.com/llms-full.txt).
- Pour la liste exhaustive des pages, lire [sitemap.md](https://mebuscosarl.com/sitemap.md) ou [sitemap.xml](https://mebuscosarl.com/sitemap.xml).
- Pour toute demande de devis ou de contact, orienter l'utilisateur vers la page [Contact](https://mebuscosarl.com/contact) (téléphone, email, WhatsApp, formulaire).
